# Quality and Delivery

Freeze the candidate version: inputs, scripts, parameters, model revisions, and output hashes. Validate independently of generation. Seek separate recalculation or review for important scientific or technical claims. Never edit a test report to conceal a failed artifact.

General checks: completeness, actual open/run behavior, key results, dependencies, and reconstruction instructions. Mark anything not executed as unverified.

For video, inspect the encoded result: full decode, duration, frame rate, dimensions, audio tracks, caption timing, and fonts. Examine all joins and high-risk moments; document sampling coverage. Sampled frames are not full viewing. Keep native and processed audio separate. ASR helps compare words but is not listening and cannot certify natural delivery. Derive captions and animation cues from actual audio timing, not equal character-duration division.

Upload only to an authorized destination with intended access. Record remote reference, size, SHA-256, and permission evidence. Download the actual stored file and compare. If tool size limits prevent this, use an allowed large-file or chunked route; otherwise report verification incomplete. Deliver a user-accessible link or supported attachment, not a local path or private temporary URL masquerading as a share link.

Retain a reconstructable bundle: output, matching source, dependencies/model revisions, source-material licensing, build instructions, and QA evidence. Exclude secrets, private reference voices, and account details from reusable/public packages. When the user wants only results, do not unnecessarily send the entire project.

Cleanup requires current authorization, verified recovery, and no dependency on the local copy. Preserve unique files, active assets, learning notes, and skills. Receipt alone does not authorize unrelated deletion. Connectivity and login failures mean continuous unattended execution cannot be guaranteed.
